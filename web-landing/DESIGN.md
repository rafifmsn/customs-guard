# CustomsGuard Landing Page Design System (Dub Reference)

This document captures the design tokens extracted from `dub-co` via the `inspo` MCP server.
All components in `web-landing/` follow the Feature Stack macrostructure and minimalist grid geometry.

## Color Palette

| Token           | Hex       | Purpose                                   |
| :-------------- | :-------- | :---------------------------------------- |
| Background      | `#ffffff` | Primary canvas background                 |
| Subtle Surface  | `#fafafa` | Card and interactive panel surface        |
| Muted Surface   | `#f5f5f5` | Table headers and pill containers         |
| Border          | `#e5e5e5` | 1px crisp structural hairlines            |
| Primary Text    | `#111111` | Display headlines and primary actions     |
| Accent Orange   | `#ec8434` | Autonomous Tariff RAG feature pill        |
| Accent Mint     | `#86c1a1` | CMA CGM Demurrage Engine feature pill     |
| Accent Lavender | `#c095e6` | Lartas Permit Guard feature pill          |
| Accent Plum     | `#aa65a0` | Evidentiary Dossier & Mailpit Alert badge |

## Typography

- Display Headline (`h1`, `h2`): `Satoshi`, 48px, weight 500, line-height 1.15.
- Body & UI Controls: `Inter`, 16px/14px, weight 400/500, line-height 1.5.
- Technical Identifiers & HS-6 Codes: `GeistMono` / `ui-monospace`.
